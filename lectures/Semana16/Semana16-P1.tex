\section{Cierre del curso}

% 3
\begin{frame}{Objetivos de la sesión}
  Al finalizar la sesión, cada estudiante debería poder:

  \begin{itemize}
    \item reconocer herramientas habituales en programación científica;
    \item distinguir editor, intérprete, terminal, repositorio y plataforma;
    \item ubicar documentación oficial para seguir aprendiendo;
    \item evaluar cuándo conviene usar cada herramienta;
    \item preparar una ruta personal de aprendizaje después del curso.
  \end{itemize}
\end{frame}

% 4
\begin{frame}{Idea central}
  \begin{alertblock}{Programar no es solo escribir código}
    También implica organizar archivos, ejecutar programas, leer documentación,
    colaborar, reportar resultados y aprender herramientas nuevas.
  \end{alertblock}

  \begin{columns}
    \begin{column}{0.31\textwidth}
      \begin{block}{Entorno}
        Donde escribimos, ejecutamos y depuramos código.
      \end{block}
    \end{column}
    \begin{column}{0.31\textwidth}
      \begin{block}{Colaboración}
        Donde compartimos cambios, revisiones y proyectos.
      \end{block}
    \end{column}
    \begin{column}{0.31\textwidth}
      \begin{block}{Comunidad}
        Donde practicamos, leemos ejemplos y seguimos aprendiendo.
      \end{block}
    \end{column}
  \end{columns}
\end{frame}

\section{Colaboración}

% 13
\begin{frame}{GitHub}
  \begin{columns}
    \begin{column}{0.22\textwidth}
      \centering
      \includegraphics[width=0.8\textwidth]{2) Plataformas/github.png}
    \end{column}
    \begin{column}{0.72\textwidth}
      \begin{block}{Qué es}
        Una plataforma para alojar proyectos de código, registrar cambios,
        discutir problemas y colaborar mediante revisiones.
      \end{block}

      \begin{itemize}
        \item Un repositorio guarda código, datos livianos y documentación.
        \item Los commits registran cambios importantes.
        \item Las pull requests permiten revisar antes de integrar.
        \item Un README explica qué hace el proyecto y cómo usarlo.
      \end{itemize}
    \end{column}
  \end{columns}

  \begin{alertblock}{Documentación}
    \href{https://github.com/}{https://github.com/}
  \end{alertblock}
\end{frame}

% 14
\begin{frame}{Previsualización: repositorio en GitHub}
  \begin{center}
    \includegraphics[width=0.92\textwidth]{2) Plataformas/preview-github.png}
  \end{center}

  \vspace{-0.15cm}
  \scriptsize
  Un repositorio muestra archivos, historial, issues, pull requests, ramas y
  metadatos del proyecto.
\end{frame}

% 15
\begin{frame}{Colaborar de manera ordenada}
  \begin{enumerate}
    \item Crear o clonar un repositorio.
    \item Trabajar en una rama para no romper la versión principal.
    \item Hacer commits pequeños y con mensajes claros.
    \item Abrir una pull request para recibir revisión.
    \item Conversar cambios, corregir y cerrar la tarea.
  \end{enumerate}

  \begin{alertblock}{Idea práctica}
    Un proyecto compartido necesita historia, instrucciones y acuerdos. GitHub
    ayuda a mantener esas tres cosas visibles.
  \end{alertblock}
\end{frame}

\begin{frame}[fragile]{Un ejemplo mínimo de LaTeX}
  El código se guarda en un archivo de texto con extensión \texttt{.tex},
  por ejemplo \texttt{ejemplo.tex}.

\vspace{0.15cm}
\begin{minted}{latex}
\documentclass{article}
\begin{document}

La ecuacion de energia cinetica es
\[
  K = \frac{1}{2}mv^2
\]

\end{document}
\end{minted}

  \begin{block}{Qué observar}
    El archivo \texttt{.tex} es texto plano. Para ver el documento final hay
    que compilarlo y revisar la salida.
  \end{block}
\end{frame}

\section{Actividad de cierre}

% 25
\begin{frame}{Ficha de exploración}
  En grupos, elijan una herramienta y preparen una ficha breve:

  \begin{itemize}
    \item nombre de la herramienta;
    \item qué problema resuelve;
    \item cuándo la usaría un estudiante de programación;
    \item enlace a documentación oficial;
    \item ejemplo mínimo de uso;
    \item recurso complementario para seguir aprendiendo.
  \end{itemize}

  \begin{alertblock}{Entrega}
    Presentación oral de 3 minutos por grupo.
  \end{alertblock}
\end{frame}

% 26
\begin{frame}{Preguntas guía para investigar}
  \begin{columns}
    \begin{column}{0.48\textwidth}
      \begin{block}{Uso}
        \begin{itemize}
          \item ¿Qué tarea facilita?
          \item ¿Qué problema evita?
          \item ¿Qué necesito instalar?
        \end{itemize}
      \end{block}
    \end{column}
    \begin{column}{0.48\textwidth}
      \begin{block}{Aprendizaje}
        \begin{itemize}
          \item ¿Dónde está la documentación?
          \item ¿Cuál es el primer tutorial?
          \item ¿Qué ejemplo puedo reproducir?
        \end{itemize}
      \end{block}
    \end{column}
  \end{columns}

  \vspace{0.45cm}
  \begin{alertblock}{Criterio}
    La mejor herramienta no es la más compleja: es la que ayuda a trabajar con
    más claridad, orden y reproducibilidad.
  \end{alertblock}
\end{frame}
